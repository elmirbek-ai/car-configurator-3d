# Кыргызстан үчүн реалдуу унаа 3D активдерин баалоо

## Максат жана учурдагы абал

Максаттуу талапкерлер: **Toyota Camry XV70 (2018–2024)**, **Hyundai Sonata DN8 (2020–2024)** жана **Kia K5 DL3 (2020–2024)**. Бул жылдар тапшырмадагы баалоо алкагы; ар бир активдин так рынок/жыл/кузов варианты өзүнчө ырасталат. Азыр бул үч унаанын биринин да лицензияланган GLB файлы долбоордо жок. Mesh аттары, өлчөмдөрү, координаттары жана лицензиялары **белгисиз**. Бул документ актив сатып алууну же жүктөөнү сунуштабайт.

Учурда колдонмо бир `/models/CarConcept.glb` жолун колдонот (`src/components/CarScene.tsx:11,175`), боёк/rim материалын атынан табат (`src/components/CarScene.tsx:12-14,191-207`), эки номердин координатын жана spoiler геометриясын ошол концептке ылайык берген (`src/components/CarScene.tsx:358-364,390-413`). Дөңгөлөк орду да концепттин конкреттүү node'доруна байланышкан (`src/components/WheelRims.ts:8-13,102-139`). Бул маанилерди реалдуу унааларга көчүрүүгө болбойт. Бул тапшырмада иштеп турган код өзгөргөн жок.

## Типтүү descriptor

Толук TypeScript келишими `src/vehicleDescriptor.ts:1-153` ичинде аныкталды. Ал **тип гана**, runtime объект же жаңы модель тандоо механизми эмес. `VehicleDescriptor` текшерилген актив үчүн төмөнкүлөрдү талап кылат:

- identity жана provenance: `id`, марка, модель, муун, жылдар, рынок, вариант, `glbUrl`, SHA-256;
- багыт/масштаб: `sourceForward`, `sourceUp`, `metersPerSourceUnit`, viewer root translation/rotation; viewer системасы **+X оңго, +Y өйдө, +Z унаанын алдына**;
- source жана viewer bounds; алдыңкы/арткы номер anchor'лору; spoiler anchor'у; төрт дөңгөлөктүн center, axle, rim/tire өлчөмдөрү;
- бөлүк картасы, функция flags, актив метрикалары жана текшерилген укук/атрибуция.

`MeshBinding.nodePath` glTF scene root'унан башталган **так node жолу**, `primitiveIndices` ошол node mesh'индеги так primitive индекстери. `expectedMaterialNames` жардамчы текшерүү гана: материал атына божомол кылууга болбойт. `PartMapping` `mapped` же `unavailable` абалын жана себебин милдеттүү кылат; бош же ойдон чыгарылган mesh аттары колдонулбайт. Картанын ролдору:

| Роль | Милдеттүү текшерүү |
| --- | --- |
| `paintPanels`, `hood` | Сырткы боёк панелдери, капот өзүнчө primitive/face топ катары так аныкталсын; carbon капот бамперге өтпөсүн. |
| `bumpers.front/rear` | Экөө капот/эшик/жарыктан өзүнчө тандалсын. |
| `doors.frontLeft/frontRight/rearLeft/rearRight` | Төрт эшиктин панелдери жана алардын айнектери чаташпасын. |
| `glass.windshield/rearWindow/leftSide/rightSide` | Терезелер фара, күзгү жана башка тунук беттерден ажыратылсын. |
| Ар бир `wheels[corner]` | `rim`, `tire`, `brakeDisc`, `brakeCaliper` өзүнчө текшерилсин; rim алмаштырганда шина/тормоз өзгөрбөсүн. |
| `lights.frontLeft/frontRight/rearLeft/rearRight` | Тонировка жана кузов боёгу жарыктарга тийбесин. |

`unavailable` баалоо маалыматында гана жарактуу: тиешелүү функция `features` ичинде `false` болушу керек. Өндүрүшкө кабыл алууда бардык негизги кузов/айнек/дөңгөлөк/жарык ролдору `mapped` болушу, бардык node жолдору жана primitive индекстери GLBден текшерилиши керек. Төрт эшик же тормоз бөлүктөрү активде жок болсо, бул талапты алмаштыруучу актив же так чектелген функция профили керек; жасалма mapping түзүлбөйт. Үч талапкер үчүн азыр `VehicleDescriptor` инстанциясы түзүлгөн жок.

## Координата, bounds жана anchor кабыл алуу эрежелери

1. GLBдеги node иерархиясын жана parent transform'дорду окуп, ар бир vertex'ти world/viewer координатына өткөрүп өлчөө. `sourceForward` жана `sourceUp` өз ара перпендикуляр болушу керек; `metersPerSourceUnit > 0`; quaternion узундугу 1ге жакын; күзгүдөй тескери (negative determinant) transform болсо өзүнчө текшерилет.
2. Унаа алды viewer'де **+Z**, өйдө **+Y**, туурасы **X** болсун. `sourceBounds` GLB бирдигинде, `viewerBoundsMeters` transform колдонгондон кийинки метрде өлчөнсүн. Өлчөмдөр унаанын конкреттүү жыл/рынок/комплектациясына тиешелүү ишенимдүү өлчөм менен салыштырылсын; ушул үч талапкерге азыр сан коюлбайт.
3. Front/rear plate `Pose3` жергиликтүү панелдин нормалына жана иш жүзүндөгү номер ордуна ылайык белгиленсин. `mountWidthMeters`/`mountHeightMeters` физикалык бош аянттан өлчөнсүн; Кыргызстандын 01–10 region жана 3 сан/3 тамга рендери эки тарапта тең батсын. Концепт моделинин координаттары көчүрүлбөсүн.
4. Spoiler anchor trunk/арткы капкактагы эки чыныгы бекитүү чекити, пайдалуу туурасы жана collision/жарака текшерүүсү менен гана берилсин. Ылайыктуу бекитүү жери жок болсо `spoilerAnchor: null` жана `features.spoiler: false`.
5. Төрт `WheelFitment` борбору, сыртка багытталган axle вектору, rim radius/width жана tire outer radius геометриядан өлчөнсүн. Custom rim тормозго жана шинага кирбей турганы ар бир бурчта текшерилсин.

## Функция flag'деринин шарты

`VehicleFeatureFlags` ичинде `bodyPaint`, `bodyFinish`, `carbonHood`, `windowTint`, `wheelFinish`, `wheelDesign`, `frontPlate`, `rearPlate`, `spoiler` бар. `true` төмөнкү далилден кийин гана берилет:

- Paint/finish — бардык сырткы боёк панелдери так карталанган; glass, light, tire, brake жана interior өзгөрбөйт.
- Carbon hood — **капоттун чыныгы бети** bumper'ден өзүнчө material/primitive/ишенимдүү face partition менен өзгөрөт; OFF учурда тандалган боёк/finish толук кайтарылат.
- Tint — windshield, side, rear glass жеке карталанган жана light/mirror өзгөрбөйт.
- Wheel finish/design — төрт rim жана tire/brake топтору айырмаланат, fitment өлчөнгөн.
- Plates — тиешелүү anchor жана жетиштүү бош орун бар; кузовго кирбейт.
- Spoiler — текшерилген эки бекитүү чекити жана реалдуу геометриялык fit бар.

Save/reset/JSON export жалпы UI функциялары, модель активинин feature flag'и эмес; кийин model id менен сактоо миграциясы өзүнчө пландалат. Азыркы функциялар өзгөртүлгөн жок.

## Веб үчүн бюджеттер

Бул сандар **сунушталган кабыл алуу чектери**, максаттуу активдерге карата өлчөнгөн жыйынтык эмес. Desktop жана mobile'га өзүнчө LOD/GLB керек болушу мүмкүн. Өлчөө compressed GLB transfer көлөмү, декоддон кийинки triangle/texture GPU баасы жана браузердеги чыныгы draw call боюнча жүргүзүлөт.

| Метрика, бир унаа | Desktop чек | Mobile чек | Эскертүү |
| --- | ---: | ---: | --- |
| GLB жүктөө көлөмү | ≤15 MiB | ≤8 MiB | KTX2 жана geometry compression мыйзамдуу/шайкеш болсо колдонулат; бюджет бүт модель үчүн. |
| Көрүнгөн triangle | ≤250 000 | ≤120 000 | Mobile үчүн LOD же өзүнчө жеңил актив; кузов силуэти жана номер аймагы бузулбасын. |
| Бир кадрдагы draw call | ≤150 | ≤100 | Chrome/браузер профилинде модель жана тюнинг бөлүктөрү менен өлчөө. |
| Декоддон кийинки texture GPU көлөмү | ≤64 MiB | ≤32 MiB | Mipmap камтылсын; файлдын compressed көлөмү менен чаташтырылбасын. |
| Эң чоң texture чети | ≤2048 px | ≤1024 px | Кичинекей badge/plate үчүн мындан да аз; көзгө көрүнгөн детал боюнча текшерүү. |

Бюджеттен ашса актив автоматтык түрдө бекитилбейт: кайсы панель/texture сапатты талап кыларын аныктап, LOD, texture атлас, material consolidation же өлчөм кыскартуу боюнча кайра баалоо жасалат. Тандалган түзмөктөрдө кадр убактысы, GPU эс тутуму, loading жана камера айлануусу өзүнчө өлчөнөт. Учурдагы CarConcept бул үч унаанын бюджети өттү деген далил эмес.

## Лицензия жана атрибуция дарбазасы

Ар бир активде `sourceUrl`, `termsUrl`, `licenseName`, `rightsHolder`, `author`, `attributionText`, текшерүү күнү жана commercial use/modification/redistribution укуктары **булактын жазуу жүзүндөгү шартынан** ырасталсын. Кузов логотиптери/соода белгилери үчүн `trademarkStatus` өзүнчө `cleared`, `requires-removal` же `not-present` деп белгиленсин. Автор/укук ээси жана файлдын SHA-256 хэши provenance жазуусуна кирсин. Укук белгисиз болсо файлды өндүрүшкө кошууга болбойт; CC же «акысыз» деген атты уруксат деп эсептөөгө болбойт. Бул документ эч бир конкреттүү Toyota, Hyundai же Kia моделинин лицензиясын ырастабайт.

## Активди аудиттөө тизмеси

- [ ] Файлдын мыйзамдуу булагы, өзгөртүү/вебде көрсөтүү/таратуу укуктары жана атрибуция текшерилди; соода белгилери өзүнчө каралды.
- [ ] GLB 2.0 структурасы, extension'дор, KTX2 декоддолушу жана браузердеги GLTFLoader жүктөөсү өттү; SHA-256 катталды.
- [ ] Так марка/муун/жыл/рынок/комплектация сүрөтү жана өлчөмү активге дал келет.
- [ ] Node hierarchy, transform, sourceForward/up, scale, bounds жана origin өлчөндү.
- [ ] Hood, front/rear bumper, төрт эшик, бардык терезе, төрт rim/tire/brake, төрт негизги light үчүн так node path жана primitive индекстер жазылды.
- [ ] Paint, glass, light, rim, tire, brake материалдары өз алдынча; cached GLB материалын өзгөртпөй clone кылууга болот.
- [ ] Капот бети bumper'ден бөлүнөт; carbon ON/OFF жана кузов finish'тери башка беттерди боёбойт.
- [ ] Төрт wheel fitment, эки номер anchor'у жана мүмкүн болсо spoiler anchor'у өлчөндү; бардык камера бурчтарында collision/жарака жок.
- [ ] Mesh triangle, draw call, GLB transfer, texture GPU/өлчөм бюджеттери desktop/mobile'да өлчөндү.
- [ ] Front/Rear/Left/Right/Top/Free 360, zoom, жарык, көлөкө, mobile көрүнүш жана browser console текшерилди.
- [ ] Config save/reset/export жана эски конфигурация миграциясы model id'ге жараша келечектеги интеграцияда текшерилет.
